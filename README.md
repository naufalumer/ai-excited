A colossal golden koi leaps off the edge of the world. One image made to get
make.fun's AI judge excited: a koi of molten gold arcs over a waterfall that
pours off a floating island into a starry night sky, a tiny wooden boat riding
the wave beneath it, spray and golden sparks bursting toward the viewer. One
thrilling moment, one clear focal point, readable at any size.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png` when that is set). It runs with Node 22 and
the standard library only, needs no network, and writes byte-identical output
on every run.
